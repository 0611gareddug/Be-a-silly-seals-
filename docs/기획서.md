> 바보 물범 직원이 되어 물고기 공장에서 **해고당하지 않고 버티는** 8인 멀티 픽셀아트 타이쿤

| 항목 | 내용 |

## 2. 등장 캐릭터

### 2-1. 플레이어 = 물범 직원
- 동글동글한 아기 물범 픽셀 캐릭터 (16×16 기준, 화면에서 3~4배 확대)
- 걸을 때 몸 전체를 뒤뚱거리고, 멈추면 꼬리지느러미를 까딱거림
- 무언가를 들고 있으면 머리 위로 들어 올린 자세가 되고, 이동 속도가 30% 느려짐
- 머리 위에 닉네임, 그 아래에 경고 아이콘(⚠️ 0~3개)
- **플레이어 충돌 있음:** 물범끼리 부딪히면 말랑하게 통통 튕겨 남 ("뽀잉" 효과음). 들고 있던 물건은 떨어뜨리지 않음

### 2-2. 사장 = 늙은 대장 물범 (내레이션 전용 NPC)
- 맵에는 등장하지 않고, 화면 왼쪽 아래 **대사창**에 얼굴 초상화로만 나옴
- 하얀 콧수염, 작은 안경, 넥타이 차림. 표정은 평소 / 화남 / 흐뭇함 / 놀람 4종
- 대사는 한 글자씩 타자 치듯 출력되고, 글자마다 "뿍" 효과음이 남
- 대사 예시
  - 시작: "오늘도 물고기는 넘쳐나고 월급은 모자라다. 일해라, 물범들!"
  - 주문: "고등어 3마리 주문 들어왔다! 90초 안에 출하해!"
  - CCTV: "지금부터… CCTV를 확인하겠다." (화남)
  - 경고: "○○○! 근무 중에 비치볼이라니! 경고 1회다!"
  - 해고: "○○○… 내일부터 안 나와도 된다." (빨간 도장 연출)
  - 구역 해금: "참치 라인이 열렸다. 비싼 놈이니 떨어뜨리지 마라."
  - 결과: "이번 달 우수 사원은… ○○○!"

## 3. 화면 흐름

```
타이틀 → 닉네임 입력(첫 실행만) → 메인 메뉴
  ├ 싱글 플레이 (봇과 함께 / 혼자 연습 / 튜토리얼)
  ├ 방 만들기 → 로비
  ├ 방 참가 (6자리 코드 입력 or 초대 링크로 바로 입장) → 로비
  ├ 꾸미기 (물범 꾸미기 상점 / 옷장)
  └ 설정 (BGM·효과음 볼륨, 조작 감도, 화질, 언어는 한국어 고정)

로비 → 게임 → 결과 화면 → 로비로 복귀(다시 하기)
```

### 3-1. 타이틀
- BGM: **타이틀 테마**
- 배경: 바다 위 픽셀 공장, 굴뚝에서 물고기 모양 연기가 퐁퐁 나옴
- 물범 직원 여럿이 화면 아래를 뒤뚱뒤뚱 지나감
- "화면을 눌러 시작" 깜빡임. 모바일에서는 오른쪽 위에 전체 화면 버튼

### 3-2. 로비
- 큰 글씨로 방 코드(예: `SEAL42`) + [링크 복사] 버튼
- 플레이어 카드 8칸: 꾸민 물범 모습, 닉네임, 준비 여부. 빈칸에는 [봇 추가 ▾] (쉬움/보통/어려움)
- 방장만 바꿀 수 있는 설정: 모드(경쟁/협동), 경쟁 시간(8/12/15분), 봇 난이도
- 오른쪽에 채팅창, 아래에 이모트 버튼
- 로비에서도 물범을 조작해 대기실을 돌아다닐 수 있음 (몸풀기 공간)

### 3-3. 게임 화면 (HUD)
- 위 가운데: 남은 시간 / 협동 모드는 Day + 목표 실적 진행 바
- 왼쪽 위: 내 돈 💰, 스트레스 게이지(초록→노랑→빨강), 경고 ⚠️⚠️⚠️
- 오른쪽 위: 순위표 (경쟁) — 이름, 돈, 경고 개수, 스트레스 막대. 해고된 사람은 회색 + 🚫
- 오른쪽: 주문 카드 최대 3장 (물고기 아이콘, 수량, 남은 시간 원형 타이머, 보상)
- 왼쪽 아래: 사장 대사창
- 방해를 받으면 화면 위에 "🐱 ○○○님이 고양이를 풀었다!" 알림

### 3-4. 결과 화면
- 시상대 연출: 1~3위 물범이 단상 위에서 점프, 해고자는 상자를 들고 퇴근하는 모습
- 통계: 번 돈, 처리한 주문 수, 받은 경고, 가장 많이 방해한 사람 / 당한 사람
- 획득 꾸미기 코인 표시 → [다시 하기] [로비로]

## 4. 공장 맵 (넓은 맵 + 구역 해금)

```
┌──────────────────────────────────────────────────────┐
│ [1 멸치] [2 고등어🔒] [3 연어🔒] [4 참치🔒] [5 황금🔒]   │  ← 위쪽: 구역 5개
│                                                      │
│ 손질대 포장대    컴퓨터   주문게시판    손질대 포장대    │  ← 가운데: 왼쪽·오른쪽 작업대
│                                                      │
│ 휴게실(소파)   청소함        🚚 출하 트럭               │  ← 아래: 휴게실 · 트럭(가운데)
└──────────────────────────────────────────────────────┘
```

> 제작 중 변경: 봇 시뮬레이션 결과 이동 시간이 너무 길어서, 손질대·포장대를 **왼쪽과 오른쪽에 한 쌍씩** 두고 컴퓨터와 출하 트럭을 **가운데**로 옮겼어요.

- 맵 크기: 약 화면 3×2배. 카메라가 플레이어를 부드럽게 따라감
- 처음엔 멸치 구역과 공용 시설(손질대·포장대·출하구·컴퓨터·휴게실)만 열려 있음
- 잠긴 구역은 벽에 "공사 중" 표지. 돈을 내면 벽이 무너지는 연출과 함께 열림
- 경쟁 모드: 플레이어마다 **각자의 공장** (같은 구조, 화면 분리)
- 협동 모드: **하나의 공장**을 모두가 함께 사용

### 4-1. 구역 / 물고기 (5등급)

| 구역 | 물고기 | 해금 비용 | 기본 가격 | 자동 생산 계수 | 업그레이드 기본 비용 | 미니게임 난이도 |
|---|---|---|---|---|---|---|
| 1 | 멸치 | 시작 | 80 | 1 | 40 | ★ |
| 2 | 고등어 | 500 | 250 | 3.5 | 180 | ★★ |
| 3 | 연어 | 2,200 | 700 | 10 | 650 | ★★★ |
| 4 | 참치 | 7,000 | 1,800 | 27 | 2,200 | ★★★★ |
| 5 | 황금물고기 (전설) | 20,000 | 6,000 | 80 | 7,000 | ★★★★★ |

- 자동 수입(초당) = 자동 생산 계수 × 레벨^1.3
- 업그레이드 비용 = 기본 비용 × 1.6^(레벨−1), 최대 Lv.10
- **출하가 = 기본 가격 × (1 + 0.35 × (레벨−1))** → 기계를 업그레이드하면 그 구역 생선 값도 올라요 (제작 중 추가)
- 봇 시뮬레이션 기준 (12분, 어려움 봇): 고등어 약 2분, 연어 약 4.5분, 참치 약 8분, 황금 약 10~11분에 해금
- 황금물고기는 **최종 구역(5)을 해금해야만** 생산 가능
- 황금물고기 출하 시 사장 특별 대사 + 전체 알림 (경쟁 모드에서는 모두에게 견제 신호)

## 5. 핵심 시스템

### 5-1. 방치형 생산 (자동 수입)
- 각 구역에는 **자동 어망 기계**가 있고, 일정 시간마다 물고기를 잡아 자동 판매함
- 기계 레벨 1~10. 레벨이 오를수록 생산 속도와 판매가가 오름
- 업그레이드 비용 = 기본 비용 × 1.6^(레벨-1)
- 기계를 업그레이드하면 픽셀 연출이 바뀜 (Lv5: 굴뚝 추가, Lv10: 반짝이는 금속 외형)
- 자동 수입은 판 전체 수입의 약 40%가 되도록 조정 → **직접 주문 처리가 더 중요**하게

### 5-2. 주문 처리 (직접 플레이)
- 주문 게시판에 주문이 최대 3개까지 올라옴 (예: "연어 2마리, 100초")
- 처리 순서: **① 수조 건지기 → ② 손질 → ③ 포장 → ④ 출하**
- 보상 = 물고기 가격 × 수량 × 1.5 (+빨리 끝내면 보너스 최대 30%)
- 시간 안에 못 끝내면 주문 실패: 보상 없음 + 스트레스 +15

### 5-3. 업무 미니게임 4종

| 업무 | 장소 | 조작 | 설명 |
|---|---|---|---|
| 🎣 수조 건지기 | 각 구역 수조 | 탭 / 스페이스 | 좌우로 움직이는 뜰채 게이지를 초록 구간에서 멈추기. 등급이 높을수록 구간이 좁고 빠름 |
| 🔪 손질 | 손질대 | 드래그 / 스와이프 | 생선 위 점선을 따라 긋기. 정확도 70% 이상이면 성공. 등급이 높을수록 선이 길고 꺾임 |
| 📦 포장 | 포장대 | 드래그 앤 드롭 | 상자 격자(3×3 ~ 4×4)에 블록 모양 생선 조각을 빈틈없이 배치. 제한 시간 있음 |
| 🚚 출하 | 출하구 | 이동 | 포장 상자를 들고 트럭까지 직접 나르기. 들고 있으면 이동 속도 -30% |

- 미니게임 실패 시: 스트레스 +5, 다시 시도 가능 (물고기는 사라지지 않음)
- 미니게임 중에도 주변이 계속 진행됨 → 반투명 팝업으로 띄워서 주변이 보이게

### 5-4. 스트레스 & 장난감 (딴짓)

**스트레스가 오르는 경우**
- 근무 중 자연 증가: 3초마다 +1
- 미니게임 실패 +5 / 주문 실패 +15 / 방해 피해 +10

**스트레스가 100이 되면** → 경고 1회 + 물범이 "으아악" 하며 3초간 기절, 스트레스 50으로 리셋

**장난감** (휴게실에서 사용하거나, 구매한 장난감을 들고 다니며 아무 데서나 사용)

| 장난감 | 가격 | 해소 속도 | 특징 |
|---|---|---|---|
| 비치볼 | 무료 (기본) | -2/초 | 코로 톡톡 튀기는 애니메이션 |
| 스퀴시 | 300 | -4/초 | 꾹꾹 누르는 애니메이션, 말랑 효과음 |
| 게임기 | 1,200 | -8/초 | 화면 빛이 새어 나와서 CCTV 경고 후 내려놓을 시간이 1.5초로 짧아짐 |
| 낮잠 베개 | 2,500 | -15/초 | 가장 강력. 대신 일어나는 데 1.5초가 걸려서 위험 |

- 장난감을 쓰는 동안에는 아무 업무도 할 수 없음

### 5-5. CCTV 불시 점검
- 60~120초마다 무작위로 발생 (경쟁 모드에서는 플레이어마다 따로 발생)
- 연출: 사이렌 + 화면 테두리가 빨갛게 깜빡임 + 사장 대사 "CCTV를 확인하겠다."
- 경고 후 **2초** 안에 장난감을 내려놓지 않으면 → 경고 1회
- 걸리면: 화면에 CCTV 화면 같은 흑백 필터 + 녹화 중 표시 + 내 물범 클로즈업

### 5-6. 해고
- 경고 3회 = 해고 (빨간 "해고" 도장이 찍히는 연출)
- **경쟁 모드:** 탈락 → 다른 플레이어 공장을 관전 (좌우 화살표로 전환), 채팅·이모트는 가능
- **협동 모드:** 30초 동안 업무 불가 → 복귀하면서 경고 0회로 초기화. 대신 팀 실적에서 -1,000

## 6. 모드

### 6-1. 경쟁 모드 (개인전, 1~8명)
- 각자 자기 공장에서 일함 (화면 분리)
- 시간: **기본 12분** (방장이 8/12/15분 중 선택)
- **승리 조건:** 시간 종료 시 해고되지 않은 사람 중 번 돈이 가장 많은 사람
- 해고된 사람은 해고된 순서대로 하위 순위

#### 컴퓨터 💻 — 방해하기 탭
공장 안 컴퓨터 앞에서 상호작용하면 창이 열림 (업그레이드 상점과 같은 컴퓨터, 탭으로 구분)

| 방해 | 가격 | 효과 | 대응 방법 |
|---|---|---|---|
| 🐱 고양이 침입 | 500 | 상대 공장에 고양이 2마리가 나타나 수조와 상자 속 생선을 훔침 | 고양이에게 가서 3번 부딪히면 도망감 |
| 💻 해킹 | 800 | 상대 화면에 글리치 노이즈가 끼고 8초간 방향키가 반대로 바뀜 | 컴퓨터로 가서 "재부팅"을 길게 누르면 즉시 해제 |
| ⚙️ 기계 고장 | 1,000 | 상대의 가장 비싼 구역 자동 기계가 연기를 내며 멈춤 | 가서 수리 미니게임(렌치 연타 3초) |
| 🧼 미끄러운 바닥 | 600 | 15초간 상대 공장 바닥이 비눗물로 미끄러움 (관성 이동) | 대걸레 위치로 가서 닦거나 버티기 |

- 대상 선택: 순위표에서 플레이어 클릭
- AI 봇의 방해: 쉬움은 안 함 / 보통은 가끔 무작위 대상 / 어려움은 1위를 집중 견제
- 남용 방지: 같은 대상에게는 20초 동안 다시 방해할 수 없음 (방해 면역 표시 🛡️)
- 방어 아이템 없음 → **직접 대응만**

### 6-2. 협동 모드 (1~8명, 하나의 공장)
- 월~금 5일. 하루 3분
- 날마다 사장이 정한 목표 실적을 채우면 다음 날로 진행

| 요일 | 목표 실적 | 특징 |
|---|---|---|
| 월 | 1,000 | 튜토리얼 수준 |
| 화 | 6,500 | 손질 주문 비중 증가 |
| 수 | 25,000 | 주문 동시 4개 |
| 목 | 85,000 | CCTV 점검 주기 단축 |

## 8. 멀티플레이

- **방식:** P2P (PeerJS 무료 중계 서버로 연결만 하고, 이후 데이터는 기기끼리 직접 주고받음)
- **방장 = 호스트:** 게임 규칙 판정(시간, CCTV, 방해 적용, 순위)을 방장 기기가 담당
- **방 코드:** 6자리 영문·숫자 (헷갈리는 0/O, 1/I 제외). 초대 링크 `…/?room=SEAL42`
- **동기화**
  - 경쟁: 각자 자기 공장은 자기 기기에서 계산. 돈·스트레스·경고만 초당 4회 방장에게 전송
  - 협동: 방장이 공장 전체를 계산. 플레이어 위치는 초당 15회 주고받고 화면에서 부드럽게 보간
- **채팅:** 최대 60자, 연속 도배 방지(1초 1회). 말풍선으로 물범 머리 위에도 3초간 표시
- **이모트 4종:** 👏 박수 / 😛 혀 날름 / 💃 꿈틀 춤 / 😴 졸음 (PC 숫자키 1~4)
- **방장 이탈 시:** 게임 종료 안내 → 메인 메뉴로 이동 (P2P 구조상 한계)
- **중간 이탈자:** 경쟁에서는 해고 처리, 협동에서는 봇이 대신함

## 15. v2 업데이트

### 15-1. 맵: 원형 도넛 구조
- 가운데 원 = 출하 트럭(허브). 안쪽 원 어디서든 들어가 출하 가능
- 둘레 4구역 (구분선 + 안내 게이트 간판): ① 수조(위, 물고기 구역 5개) → ② 손질(왼쪽, 손질대 3) → ③ 포장(아래, 배선 포장대 3 · 청소함) → ④ 사무·휴게(오른쪽, 컴퓨터 · 주문 게시판 · 소파)
- 구조물 약 2배: 수조 6×4, 작업대 4×3, 컴퓨터 3×3, 트럭 8×5. 맵이 커진 만큼 이동 속도 132px/초
- 바닥 동선: 🔵 수조→손질, 🟢 손질→포장, 🟠 포장→트럭 (색깔 점선 화살표)

### 15-2. 인테리어
- 바깥 벽을 따라 장식 컨베이어 (생선·상자가 무작위로 흘러감), 벽 창문(갈매기), 포스터, 시계, 환풍기
- 구역별 소품: 계기판·밸브·배전반·증기구(수조), 얼음 상자·생선 바구니·장화·호스·그물(손질), 빈 상자 더미·테이프·팔레트(포장), 자판기·화분·TV·정수기·사물함·러그(사무·휴게), 지게차·콘(허브)
- 움직이는 부품, 사용 반응(칼질·포장 램프·모니터), 트럭 짐칸에 상자가 쌓임, 주문 게시판 메모, 그림자·입체 음영
- 기계 레벨 외형: Lv4 굴뚝, Lv7 경광등, Lv10 금빛 / 잠긴 구역은 비닐 커버 + 공사 테이프
- 마감 직전 붉은 경광 조명

### 15-3. 포장 미니게임: 배선 퍼즐 (발전기식)
- 같은 색 단자 잇기. 퍼즐은 정답 선이 판을 빈틈없이 채우도록 생성, 다 이으면 빈칸이 있어도 성공
- 4×4 3색 20초 / 5×5 4색 25초 / 6×6 5색 30초
- 드래그 보정(가장자리 잡기, 칸 건너뛰기 보간, 경계 흔들림 방지), 단자 탭하면 그 색 지우기, 숫자 표시(색맹 보조), 다른 선을 지나가면 그 선이 끊김

### 15-4. UI · 가독성
- 다음 할 일 안내문(시계 아래), 화면 밖 목표 방향 화살표(설정에서 끄기), 목표 구조물 강조 테두리
- 🗺️ 지도 (탭 또는 M): 구역 색, 시설 아이콘, 내 위치, 고양이, 고장 기계, 주문 들어온 수조 깜빡임
- 구역별 색 통일, 맵 글자 크게 + 외곽선
- 메인 메뉴: 공장 정문 배경(출근하는 물범들) / 로비: 출근 카드(준비하면 도장) + 게임 방법 카드 4장 / 결과: 월급 명세서
